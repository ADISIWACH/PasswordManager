# 🔒 PassVault • Modern Password Manager

A fast, responsive, and private password manager built with **React 19**, **Vite**, and **Tailwind CSS**.

---

## ✨ Key Features

- 👤 **Client Authentication**: Seamless login and registration with Full Name & Password.
- 🔐 **Isolated Local Storage**: Each client's passwords are stored separately and encrypted locally on the device.
- ⚠️ **Safe Delete Workflow**: Interactive warning confirmation modal before deleting any stored password.
- ✏️ **Edit & Update Flow**: Smoothly edit existing entries and replace previous versions with latest changes.
- 💾 **Final Save & Sync**: Dedicated button to commit all passwords to storage before leaving, with tab close warnings (`beforeunload`).
- ⚡ **Strong Password Generator**: Generate 16-character strong passwords with a single click.
- 🔍 **Real-Time Search**: Instantly filter websites and usernames.
- 📋 **One-Click Clipboard Copy**: Quickly copy URLs, usernames, and passwords with toast notifications.
- 🎨 **Custom Theme**: Styled with rich deep marine teal (`#092328`), forest teal (`#12544F`), and vibrant jade accents (`#2A835F`).

---

## 🚀 Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Typography**: [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans) & [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono)
- **Notifications**: [React-Toastify](https://fkhadra.github.io/react-toastify/)

## 🛠️ Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/ADISIWACH/passwordmanager.git
   cd passwordmanager
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
